# 口味访谈题本

给 agent 用：按用户选的深度挑题。**问完要整理成 `answers.json`**（字段见 `references/taste-schema.md`）。

访谈目标不是"收集标签"，是拿到四类东西：

1. **已看/已读名单** —— 排重用，比任何标签都准
2. **排斥信号** —— 一票否决项，比喜好更能砍噪音
3. **层次结构** —— 谁在"主动消费"、谁只是"陪伴"
4. **体验距离** —— 用什么距离和这个媒介相处（旁观/操控/被推着走）

---

## 0. 开场（任何深度都要问）

> 我想给你做一份"内容片单"，每周/每月推卡片。为了不推垃圾，先问几个问题。
> 你可以选择：**跳过**（用通用的跑）/ **大概**（3 个问题）/ **普通**（分媒介各两三题）/ **细致**（逐条对齐，可能追问）。

先确认**媒介权重**：

1. 你现在花时间最多的是哪个？番剧 / 网文 / 视频 / 游戏 / 音乐 / 电影
2. 哪几个是"每天都会碰"，哪几个是"想起来才看"
3. 有没有已经在用、但**不想被打扰**的（比如不想收到番剧推荐）

> 这一步决定排几张卡。用户只看番剧，就别给他建音乐月报。

---

## 1. 大概（3 问，1 分钟）

1. **最近三个月最喜欢的三部/三本是什么？**（要具体名字）
2. **最近弃掉的、或者看两眼就关掉的是什么？为什么弃？**（弃书原因比喜好有用）
3. **有没有那种"一眼看到就烦"的东西？**（比如降智爽文、情感直球、纯卖蠢、无脑开挂）

拿到这三条就能跑：已看名单排重 + 弃书原因提炼排斥信号。

---

## 2. 普通（分媒介各 2–3 题，5 分钟）

### 番剧 / 影视

1. 最近**看完并且想推荐给别人**的两部？（排重 + 正样本）
2. 有没有**看了三集就弃**的？弃在什么地方？
3. 你能接受的**最"重"的题材**是什么？（恐怖 / 战争 / 政治 / 悲剧结局）
4. 有没有一部是你会**反复重看**的？为什么？

### 网文

1. 现在**在追**的（书名 + 大概在什么进度）？—— 这是排重名单，最重要
2. **弃过**的书？弃在第几章、什么原因？（套路重复 / 系统崩坏 / 换地图 / 文笔）
3. **偏好分类**：科幻 / 玄幻 / 仙侠 / 都市 / 历史 / 游戏 / 轻小说 / 悬疑
4. 有没有**认作者的**？（认作者比认分类准，比如"远瞳的全追"）
5. **后宫 / 感情线**接受度：可以但要博弈 / 无所谓 / 不要

### 音乐

1. 最近**整张专辑循环**的是哪几张？（注意：问专辑，不问单曲）
2. **从小听到大**的那批歌手是谁？（这些是"陪伴型"，**以后不会推给你**）
3. 有没有**最近一年新发现**的艺人？
4. 什么场合会主动听歌：干活背景音 / 路上 / 睡前 / 专门坐着听

### 游戏（如果用户选了这个）

1. 最近**打开过**的游戏？（不一定通关）
2. 弃游原因：太难 / 太长 / 需要连续大块时间 / 没朋友一起
3. 喜欢**自己规划**还是**被剧情推着走**？

---

## 3. 细致（逐条对齐，15 分钟，可追问）

按四组轴问，每组都要拿到"正例 + 反例 + 边界"：

### A. 体验距离（最重要）

> 同一个题材，换个视角你就可能从喜欢变讨厌。

1. 恐怖片你能看吗？恐怖**游戏**呢？—— 区分"旁观恐惧"和"零距离恐惧"
2. 竞技：看比赛可以吗？每天排位呢？—— 区分"观赛"和"打卡"
3. 策略游戏你喜欢**自己规划**（文明/群星）还是**被剧情牵着**？
4. 3D 建造类（戴森球那种）你实际玩得动吗？还是更喜欢 2D/平面系统？
5. 有没有"设定我极爱、但实际玩不下去"的例子？—— 这类信息最值钱

### B. 情感表达

1. 你能接受**直球告白**吗，还是更喜欢"藏在动作里的"？
2. 结局：要圆满 / 要留白 / 要惨但合理？
3. 主角**失败**你受得了吗？（失败也是叙事 vs 只想看爽）

### C. 系统与代价

1. 主角开挂（无代价变强）你能接受吗？
2. 世界**不围着主角转**（配角会死、努力没回报）你吃这套吗？
3. 作品**后期崩坏**你的容忍度：只要前 2/3 好就行 / 必须完整 / 直接弃

### D. 层次结构（只对音乐和作者适用）

1. 哪些艺人/作者你会**主动等新作**？（→ 内核层，会推）
2. 哪些是**熟到不用记**、听到就换台的？（→ 陪伴型，永不推）
3. 有没有**曾经很爱、现在已经不听**的？（→ 阶段层，当前不推）
4. 干活时放的背景音和"专门听的"是两拨吗？（→ 功能层，不算推荐）

## 4. 整理成 answers.json

```json
{
  "depth": "normal",
  "name": "用户希望被怎么称呼（留空 = 卡片标题中性）",
  "lines": {"A": "史诗时间感…", "B": "延迟情感传递…"},
  "anime_watched": ["葬送的芙莉莲", "摇曳露营"],
  "anime_avoid": ["长期 PVP 打卡", "第一人称生存恐怖"],
  "anime_hits": ["吹奏乐", "政治博弈"],
  "novels_read": ["黎明之剑"],
  "novels_dropped": ["玄鉴仙族"],
  "novel_categories": ["科幻", "轻小说"],
  "novel_authors": {"远瞳": 5},
  "core_artists": ["Aimer", "ヨルシカ"],
  "companion_artists": ["周杰伦"],
  "music_avoid": ["电音 drop"],
  "game_series": ["薩爾達", "異度神劍"],
  "game_hits": ["模擬", "戰棋"],
  "game_avoid": ["排位", "大逃殺"],
  "game_caution": ["恐怖", "射擊"],
  "voice": {"anchor": "低音区女声", "f0": "200-260Hz"},
  "notes": "旁白不要给表演指令"
}
```

拿不准的字段**留空**——空值是「不筛」，不会报错。宁可少填，也别编。

三条容易填错的：

- **`anime_watched` 是「已看过」，不是「你喜欢」**。访谈里拿到的推荐向列表别塞这里，
  塞错的后果是卡片把你爱看的全排掉。不确定就留空，之后用 `setup/mark.py` 补。
- **`core_artists` vs `companion_artists`**：前者是「会主动等新作」，后者是「从小听到大、
  听到就换台」。写错的后果是月报里出现周杰伦——这比空着更烦。
- **游戏口味词写短**（「模擬」「戰棋」「排位」），它们是拿去和标题做子串匹配的，
  写成句子永远匹配不到。

## 5. 访谈的规矩

- **别一次问十个**：一轮 3–4 个，问完给个回执（"记下了：X/Y/Z"）再继续。
- **别把答案复述成标签**（"所以你喜欢系统流的爽文"）——用户讨厌被贴标签，直接记原话。
- 用户说"随便""都行"时，**换更具体的问法**（"那《OO》和《XX》你选哪个"），而不是自己编。
- 访谈结果要给他看一眼再落盘：**人名、书名会记错，让他纠正**。
